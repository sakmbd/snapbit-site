# snapbit-site

Public website for **Snapbit**, a free Chrome extension: *Small tools. Big productivity.*

Published with GitHub Pages at https://sakmbd.github.io/snapbit-site/

- `index.html` – product page
- `privacy-policy/index.html` – privacy policy
- `assets/` – stylesheet, screenshots, Snapbit mark and the Roboto font (Apache License 2.0, see `assets/fonts/LICENSE-roboto.txt`)

Plain static HTML and CSS: no build step, no JavaScript, no analytics.

Install Snapbit from the [Chrome Web Store](https://chromewebstore.google.com/detail/convert-2-case/jkehbmbghegdemomfhkcbdddpibnjppe).
